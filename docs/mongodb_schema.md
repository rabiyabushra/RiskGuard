# RiskGuard: MongoDB Schema & Database Architecture 🍃

This document outlines the database design for persisting RiskGuard project data, real-time telemetry, model predictions, risk analyses, and mitigation recommendations.

---

## 1. Database Architecture Overview

- **Database Name:** `riskguard_db`
- **Primary Collections:**
  1. `projects`: Complete processed infrastructure project document (demographics, costs, progress, infrastructure).
  2. `predictions`: ML inference outputs (delay probability, predicted risk class, model version).
  3. `risk_analysis`: SHAP feature importance, top delay contributors, sensitivity metrics.
  4. `recommendations`: Actionable mitigation strategies generated by LLM / domain heuristics.

---

## 3. Recommended Indexes

To ensure fast geospatial and filter queries in the FastAPI and React dashboard:

```javascript
// Unique project index
db.projects.createIndex({ "project_id": 1 }, { unique: true });

// Filter indexes
db.projects.createIndex({ "location.state_std": 1 });
db.projects.createIndex({ "sector": 1 });
db.projects.createIndex({ "timeline.is_delayed": 1 });

// Prediction query index
db.predictions.createIndex({ "project_id": 1 });
db.predictions.createIndex({ "risk_category": 1 });
db.predictions.createIndex({ "risk_score": -1 });
```

## 4. PyMongo Ingestion Helper Snippet

```python
from pymongo import MongoClient

def get_mongo_client(uri: str = "mongodb://localhost:27017"):
    client = MongoClient(uri)
    db = client["riskguard_db"]
    return db

def insert_master_projects(df_master, db):
    records = df_master.to_dict(orient="records")
    result = db.projects.insert_many(records)
    print(f"Inserted {len(result.inserted_ids)} project documents.")
```
